# Dummy Data Assets

A collection of dummy data assets for development, testing, and prototyping.

## Overview

This repository currently contains sample CSV files for use as source data in SSIS packages. The datasets are fictional and intended for development and testing only.

## Repository Structure

```text
.
└── ssis/
└── x_sbt_dummy/
```

## Usage

Use the CSV files in the `ssis/csv source/` directory as input for:

- SSIS package development
- ETL testing
- Data migration testing
- Integration testing
- Demonstrations and training

## Guidelines

- All data must be fictional or synthetic.
- Do not commit production or sensitive data.
- Keep filenames descriptive and organized.
- Maintain consistent CSV formatting (headers, delimiters, encoding).

## Contributing

When adding new datasets:

- Place them under `ssis/csv source/`.
- Use clear, descriptive filenames.
- Ensure the data is safe to share publicly.

## Disclaimer

All datasets in this repository are dummy data created for development and testing purposes only. Any resemblance to real individuals, organizations, or data is purely coincidental.
